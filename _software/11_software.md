dialectid is a set of algorithms to detect the dialect of a given text. For example, given a text written in Spanish, dialectid predicts the Spanish-speaking country where the text comes from. It is available for Arabic, German, English, Spanish, French, Dutch, Portuguese, Russian, Turkish and Chinese.
